# Glossary

| Term | Meaning |
|------|---------|
| **BPO** | Buyer Purchase Order — commercial order to a buyer |
| **WO** | Weaving Order — work ticket to own shed or external weaving vendor; often linked to a BPO |
| **Job card** | Shop-floor work ticket broken out from a BPO (weaving/dyeing/etc.) |
| **Greige / Grey** | Undyed woven fabric |
| **Job-work** | Sending material to an external factory for a process step |
| **4-point** | Fabric inspection scoring defects per yardage |
| **DTRE** | Duty and Tax Remission for Exporters (Pakistan) — track import consumption vs export |
| **FBR** | Federal Board of Revenue — e-invoicing / IRN / QR |
| **Multi-UOM** | Same material tracked as kg, meters, pieces, lbs, bales across stages |
| **Process pack** | Optional product module (Yarn, Weaving, Dyeing, Fabric purchase) |
| **Paid add-on** | Accounting/FBR/Reporting, Analytics, or LoomSage |
| **Profile** | Tenant preset: `integrated` \| `weaving` \| `dyeing` \| `converter` |
| **Golden path** | Integrated mill journey Yarn → Dispatch (FLOWS J0–J8) |
| **Journey status** | `draft` → `persona-ready` → `client-validated` → `build-ready` |
| **build-ready** | Journey may receive feature PRs on `develop` (or persona-ready waiver) |
